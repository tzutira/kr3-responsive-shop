# Публикация практической №14

Практические №12 и №13 уже в main (PR #1 и #2). Нужен один push и один PR, порядок коммитов сохраняется внутри ветки автоматически. Во время подготовки push не выполнялся.

## 1. Отправить финальную ветку

В терминале VS Code из папки проекта:

```bash
git switch fix/kr3-final-check
git status
git push -u origin fix/kr3-final-check
```

Не отправлять повторно ветки feature/responsive-layout и feature/a11y-lighthouse-audit.

## 2. Создать PR

Base: `main`. Compare: `fix/kr3-final-check`.

Название: `Complete KR3: responsive NOIR watch gallery and final audit (Practice 14)`

Описание для вставки:

```markdown
Завершена КР №3: вместо одинаковых SVG-заглушек добавлена коллекция NOIR с тремя фотографическими ракурсами каждой модели. Главная получила макрофото часов и оформление в чёрной, белой и серебристой палитре.

- WebP, srcset/sizes и picture; ручные слайдеры на главной, в каталоге и на странице товара.
- Мобильное меню с Escape и возвратом фокуса, сворачиваемые фильтры, поиск, сортировка и пустое состояние каталога.
- Карточки характеристик на мобильном экране и семантическая таблица на desktop.
- Форма обратной связи на странице контактов; сохранены доступность и валидация №13.
- README с итогом КР №3, самостоятельными доработками и порядком демонстрации.

Проверка: 25 сочетаний пяти страниц и ширин 360/430/768/1024/1440 px, основные сценарии меню, каталога, слайдеров, диалогов и форм. Переполнения и ошибок JavaScript не обнаружено. Lighthouse Accessibility — 100/100 на всех пяти страницах; актуальные HTML/JSON в lighthouse/practice14-*.

Изображения — ИИ-визуализации учебных моделей NOIR. Цены и характеристики демонстрационные, сервер и оплата не подключены. КР №4 здесь только поставлена как следующая работа в отдельном репозитории.
```

## 3. Слить PR и проверить Pages

После просмотра diff выполнить Merge pull request. Затем:

```bash
git switch main
git pull --ff-only origin main
```

Отдельный push main не нужен. В GitHub → Settings → Pages проверить публикацию из main, папка / (root). После успешного развёртывания проверить https://tzutira.github.io/kr3-responsive-shop/ и переходы на каталог, товар, заявку и контакты. Свежую версию №14 нельзя опубликовать до push и слияния.

В СДО отправить https://github.com/tzutira/kr3-responsive-shop .
